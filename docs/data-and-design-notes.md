# 泰拉观测站 · TERRA GEOGRAPHIC

《明日方舟》非官方中文交互地理档案。静态 HTML、CSS 和原生 JavaScript，无运行时外部依赖。

## 全干员资料（2026-10-26 快照）

已逐项收录 434 个正式干员形态，按游戏异格分组与阿米娅职业切换合并为 394 位干员；另保留博士、魏彦吾、安多恩 3 位非干员，共 397 份人物页。名单与同日读取的 PRTS「干员一览」完全对应，缺失、额外及重复形态均为零。限定、联动和机器人均包含；29 个特殊模式临时单位、召唤物与陷阱不计入正式干员图鉴。

每个形态单独保留职业、分支、星级、位置、技能名称和基础档案事实字段。人类的出身地与机器人的产地区分；未公开与遮蔽字段保持原口径，不反推年龄、种族或国籍。形态切换后的身高、经验等变化不覆盖原形态。人物页提供独立导读、组织联系、地区关联及各形态的外部完整档案入口，不转载整篇剧情档案或战斗数值表。

公开游戏数据来自 Kengxxiao/ArknightsGameData 的固定提交 `fe7d8d05edc36cf5678a24bfe9e84e891f6cf7ad`。人物导读保留首批 81 位干员的复核稿，其余 313 份由 dsh 根据实际取得的游戏客观履历与基础档案撰写；对有版本冲突的字段附说明，并移除两处涉及战争结局与组织消亡的叙述。版本与原始文件 SHA-256 记录于 `data/operators-provenance.json`。这是公开资料快照，不表示每个形态目前都能在游戏中获得。

434 个形态全部配备原始游戏头像，来自 Aceship 素材镜像和 PRTS 文件库；每个文件的来源、校验值与下载途径保存在 `data/character-portrait-sources.json`。PRTS 图片按文件 API 的 SHA-1 复核，全部本地文件另存 SHA-256；没有重绘、拉伸或生成肖像。原始图像权利归相关权利方所有。

- `data/operator-source.json`：从固定源文件提取的 434 形态基础字段，含官方人物分组。
- `data/curated-characters.json`：首批复核档案；`data/operator-summaries.json`：后续 313 位导读及资料限制。
- `node scripts/import-operators.mjs`：合并资料、维护原人物链接与异格别名，生成 `data/characters.json` 及 `data/operator-coverage.json`。
- `node scripts/build-characters.mjs`：校验所有形态、字段、图片与来源并生成前端数据。
- `python3 scripts/normalize-operator-source.py <源文件目录>`：验证下载文件 SHA-256，按固定游戏表及公开 Wiki 名单重建规范化资料；原始下载与名单缓存不随仓库分发，下载版本与校验值见来源清单；现有规范化快照可直接构建。

搜索包含 397 人物、18 地区、66 地点、49 组组织、10 世界设定、29 篇目，共 569 条资料。支持 479 个中英日文检索别名、职业、分支及技能名称；搜索具体异格时打开同一人物并展开对应形态。人物索引按地区、职业、星级和条目范围筛选；职业与星级要求同一形态同时满足。每次显示 60 人，可以继续展开，避免一次渲染整个目录。

已通过全名录覆盖、434 头像校验、全部基础字段与技能引用、JavaScript 语法、检索测试及隔离 LinkeDOM 逻辑检查，包括对应异格展开、分页、非干员筛选、职业与星级交叉筛选、地区返回和分享链接恢复。此轮浏览器连接仍不可用，未完成真实浏览器像素与手机布局复核；LinkeDOM 不作为视觉验证。

## 体验

- 根据底图的纸白、灰绿与岩石色提供白天配色；页顶可切换夜间，浏览器记住选择。
- 依据《大地巡旅》行政概略图提供 18 个国家与地区的可点击轮廓，带立体倾斜和贴合底图的选中高亮。
- 拖拽、滚轮与双指缩放；键盘方向键平移、Home 归位、`/` 搜索。
- 地名、英文和主题搜索，空查询地区列表，键盘方向键选中与 Enter 定位。
- 主题筛选后回到全图；三条导览显示阅读顺序连线、站序，并支持跳站。
- 18 份扩展地区档案：54 个主题章节、66 个地点、49 组组织与地方力量、29 条延伸阅读。
- 4 个基础世界设定加 6 个新增词条，共 10 项；原图与测绘／全息视图切换，并可切换立体或平面视角。
- 人物、异格、技能、国家、城市、组织与篇目名称搜索，自动切到对应档案或分类。
- 探索标记与已打开的地区进度保存在当前浏览器 localStorage 中。
- 常驻地区索引、我的标记和随机探索；随机优先选择尚未打开的地区。
- 地区链接可以复制分享，重开链接后定位同一份档案。
- 桌面选择地块后向左聚焦，右侧展开玻璃档案卡；手机采用底部档案面板，可展开阅读，选中地区保持在面板上方。
- 明确的键盘焦点、搜索选中状态，以及系统减少动态效果偏好支持；提供独立动效开关，偏好保存在当前浏览器。

## 运行

资料源文件位于 data/expanded-content.json；编辑后运行 node scripts/build-archive.mjs，生成 dist/archive-data.js。

由静态服务器提供 `dist/`。GitHub Pages 发布方法见仓库根目录 README。

## 地块与标志

`data/region-geometry.json` 保存按原生 1280×822 底图描出的 18 个地区、37 处分离区域和内部空隙；运行 `node scripts/build-region-geometry.mjs` 生成 `dist/region-geometry.js`。构建时核对底图 SHA-256，底图改变时禁止沿用旧轮廓。JPEG 细线受文字遮挡和实拍模糊影响的部分，参考相邻边缘补线；这不是行政 GIS 数据。第二轮逐区复查记录写入每个地区的 `review`；构建检查地区覆盖、分离区域与孔洞数量、闭合路径、边界范围及底图哈希。已删除旧简化轮廓，几何资料载入失败时只保留标签索引，不显示旧的错误地块。选中与悬停不再将区域独立抬升，底图、SVG 和纹理始终使用同一坐标与透视变换。17 个地区使用未改绘的游戏阵营 PNG，卡兹戴尔采用按底图纹章轮廓描摹的独立透明 SVG，避免夹带照片杂线；素材来源及透明边界记录在 `data/insignia-sources.json`。标志位置依底图纹章锚定，并与底图投影同步。立体效果通过 CSS 变换和 SVG 图层实现，无 WebGL 或外部运行时依赖。

## 官方字标与设定图示

页首与档案页脚采用官网原版《明日方舟》SVG 字标，保留矢量路径；页签采用官网罗德岛徽标。世界设定中的源石、源石技艺、移动城邦、感染者和罗德岛使用官网原始 PNG，页面按透明边界显示以统一视觉尺寸，不改绘图形或拉伸比例。原始资源保存在 `dist/assets/official/`，官方 URL、内联元素 ID、显示边界与 SHA-256 记录于 `data/official-asset-sources.json`。

其他五个概念使用语义对应的本站线条示意图；通用操作图标统一线宽与端点。站名及「非官方地理档案」始终独立于官方字标显示；资料说明区区分官方素材、游戏素材镜像与卡兹戴尔描摹图。
