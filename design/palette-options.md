# 泰拉观测站配色提案

目标：保留地图优先、玻璃面板、原始图标与字体，提供四套足够不同的颜色供用户选择。所有版本展示炎的同一相机视角与档案；地块和资料不变。用户已选择 A；正式站默认采用 A，昼夜开关的明亮模式使用 B。C、D 与其他独立预览由 URL 的 palette 参数启用。

| 版本 | 基底 / 面板 / 正文 / 次级文字 / 强调 |
| --- | --- |
| A 黑曜终端 | #171b21 / #252b34 / #edf0f4 / #b3bdca / #e6bf65 |
| B 雾白测绘 | #dfe7f0 / #f6f9fd / #23374b / #52677e / #315f9c |
| C 深林旧金 | #142822 / #243d33 / #e7eee6 / #b3c3b4 / #cbb67f |
| D 暮紫银红 | #272633 / #373541 / #eeebf4 / #c0b8cc / #d7a3b4 |

文字沿用苹方/思源黑体正文和地图现有宋体标题，保持字号与对齐一致。面板正文与背景加强分离，地图比面板稍低对比。强调色只用于当前国家、标签、焦点和关键按钮。

对照页：

    标题 / 返回现有地图
    同一地区、同一视角的说明
    A [实际地图 + 档案]   B [实际地图 + 档案]
    配色 / 完整体验链接   配色 / 完整体验链接
    C [实际地图 + 档案]   D [实际地图 + 档案]

窄屏按一列排列，完整体验链接打开真实可操作页面。缩略预览不接收交互，避免误缩放；不把滚动截在 iframe 内。

复核：黑黄源于方舟终端语汇；雾白采用清晰的冷蓝而非当前泛绿；深林采用黄灰绿而非蓝绿；暮紫采用含灰的矿物色，避免霓虹紫渐变。四版大胆之处仅在配色，保留同一布局以公平比较。不额外加装饰、纹理或动画。
